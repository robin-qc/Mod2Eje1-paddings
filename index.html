05 Box-Sizing: Modo de Cálculo

Comparación de algoritmos de cálculo dimensional. Impacto en el layout final.

content-box (modo heredado)

width declarado: 240px

padding aplicado: 24px

Ancho real: 288px

Width + padding = total

⚠️ El padding se SUMA al width declarado, causando expansión dimensional no intencionada

border-box (modo moderno)

width declarado: 240px

padding aplicado: 24px

Ancho real: 240px

Padding incluido en width

✅ El padding se RESTA del width declarado, manteniendo dimensiones predecibles

06 Display Type & Padding

Comportamiento diferencial según el tipo de display. Consideraciones de layout.

Elementos Inline (display: inline)

Este es un elemento inline con padding dentro del flujo de texto. Observa cómo el padding horizontal funciona normalmente, pero el vertical no afecta la altura de línea, causando superposición con contenido adyacente.

Elementos Inline-Block (display: inline-block)

Este es un elemento inline-block con padding dentro del texto. Combina comportamiento inline con capacidades block: el padding funciona correctamente en todos los lados y respeta el flujo de línea.

Elementos Block (display: block)

Elemento block con padding. Ocupa todo el ancho disponible del contenedor padre. El padding funciona uniformemente y el elemento fuerza un salto de línea completo.

08 Referencia del Sistema

Sintaxis completa del sistema de padding CSS. Documentación técnica.

/* ===== SISTEMA DE PADDING ===== */

/* Un valor único (simétrico 4 lados) */
padding: 20px;

/* Dos valores (eje Y | eje X) */
padding: 10px 20px;      /* vertical | horizontal */

/* Tres valores (top | X | bottom) */
padding: 10px 20px 30px; /* top | horizontal | bottom */

/* Cuatro valores (sentido horario) */
padding: 10px 15px 20px 25px; /* top | right | bottom | left */

/* ===== CONTROL POR LADO ===== */
padding-top: 10px;
padding-right: 15px;
padding-bottom: 20px;
padding-left: 25px;

/* ===== UNIDADES DE MEDICIÓN ===== */
padding: 16px;           /* Píxeles (fijo) */
padding: 1rem;           /* Relativo al root font-size */
padding: 1em;            /* Relativo al font-size del elemento */
padding: 5%;             /* Relativo al ancho del contenedor padre */

/* ===== VALORES ESPECIALES ===== */
padding: inherit;        /* Hereda del padre */
padding: initial;        /* Valor inicial */
padding: unset;          /* Combina inherit/initial */
padding: 0;              /* Reset completo */

/* ===== PATRONES COMUNES ===== */

/* Botones estándar */
.btn {
    padding: 12px 24px;      /* Proporción 1:2 */
    box-sizing: border-box;  /* ✅ Siempre usar border-box */
}

/* Inputs de formulario */
.input {
    padding: 12px 16px;      /* Espacio interno cómodo */
    box-sizing: border-box;
}

/* Cards y paneles */
.card {
    padding: 24px;           /* Espacio estándar */
    box-sizing: border-box;
}

/* Elementos inline con padding */
.inline-element {
    display: inline-block;   /* ⚠️ Necesario para padding vertical */
    padding: 8px 16px;
}

/* ===== BOX-SIZING (CRÍTICO) ===== */
*,
*::before,
*::after {
    box-sizing: border-box;  /* ✅ Mejor práctica global */
}

/* ===== RESPONSIVE PADDING ===== */
.elemento {
    padding: 16px;           /* Mobile first */
}

@media (min-width: 768px) {
    .elemento {
        padding: 24px;       /* Tablet */
    }
}

@media (min-width: 1024px) {
    .elemento {
        padding: 32px;       /* Escritorio */
    }
}

/* Padding por eje */
.py-1 { padding-top: 4px; padding-bottom: 4px; }
.px-2 { padding-left: 8px; padding-right: 8px; }

/* ===== MEJORES PRÁCTICAS ===== */

1. Siempre usar box-sizing: border-box
2. Preferir unidades relativas (rem/em) para escalabilidad
3. Implementar estrategia mobile-first
4. Usar utilidades CSS para consistencia
5. Considerar accesibilidad (espaciado mínimo 44px para toque)
6. Mantener proporciones consistentes (1:2 para botones)
